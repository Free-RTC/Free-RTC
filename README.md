## Free-RTC v2.0
Free-RTC is a free communication platform that offers completely free, end-to-end encrypted voice, video, chat, screen sharing, file sharing, polls, and much more, all without tracking any user data.
Free-RTC is primarily browser-based at https://free-rtc.web.app, but desktop apps for Windows and MacOS are actively being worked on!
## Features
### Communication
- Voice & video chat w/ mute & deafen
- Text chat
- Screen sharing at up to 1080p60
- Unlimited file size file sharing
### Room
- 1000 total rooms can be made at once
- Optional room password for security
### Chat
- Reply to messages
- React with emoji
- Copy messages
- Edit messages
- Unsend messages
- Private messaging
- Expiring messages
- Create polls
- Use text-to-speech to read your messages out loud
### Soundboard
- Upload any sound file for the soundboard
- Export and import an entire soundboard in 1 click
- Play all & Stop all buttons for when it gets crazy
- Custom soundboard volume
### Settings
- Custom video quality
- Custom keyboard shortcuts
- Built-in browser notifications
- Remove limits in the settings menu
and more (WIP)
