## Free-RTC v2.0
Free-RTC is a free communication platform that offers completely free, end-to-end encrypted voice, video, chat, screen sharing, file sharing, polls, and much more, all without tracking any user data.
Free-RTC is primarily browser-based at **[this link](https://free-rtc.web.app)**, but desktop apps for Windows and MacOS are actively being worked on!
## WebRTC
Free-RTC uses WebRTC for all communication features, so data is sent only between connected users instead of being stored on a server, so messages and files are not persistent.
Be careful when using WebRTC on metered connections, as it uploads data to every connected user, skyrocketing data usage with many connected users.
Also beware, WebRTC can expose IP addresses if other connected users know how to see it, which could leak your general location to the other person. Use a VPN if you are connecting to others you don't trust for extra security.
## Features
### Communication
- Voice & video chat w/ mute & deafen
- Text chat
- Screen sharing at up to 1080p60
- Unlimited file size file sharing
### Room
- 1000 total rooms can be made at once
- Optional room password for security
- Dark & light mode option
### Chat
- Reply to messages
- React with emoji
- Copy messages
- Edit messages
- Unsend messages
- Private messaging
- Expiring messages
- Create polls
- Use text-to-speech to read your messages out loud
### Soundboard
- Upload any sound file for the soundboard
- Export and import an entire soundboard in 1 click
- Play all & Stop all buttons for when it gets crazy
- Custom soundboard volume
### Settings
- Custom video quality
- Custom keyboard shortcuts
- Built-in browser notifications
- Remove limits in the settings menu
- Customizable interface sound effects
### Account
- Completely optional account system
- Custom interface color if you have account
- Saves the following data to the Free-RTC servers for your account:
  - Bio
  - Name color
  - Profile link
  - Your settings and preferences
  - Your username
- No message, file, voice or video data, or anything other than the above, is saved to the Free-RTC servers with or without an account.

### iOS
iOS may eventually have a .ipa, but for now, use the mobileconfig **[here](https://raw.githubusercontent.com/free-rtc/free-rtc/refs/heads/main/app/iOS/Free-RTC.mobileconfig)**.
Once you open the file on iOS, go to Settings->General->VPN & Device Management->Free-RTC and Install. It isn't signed because I am not rich so make sure you understand what it does.
Then go to your home screen, look for the Free-RTC icon, and bam! You have a psuedo-app.
