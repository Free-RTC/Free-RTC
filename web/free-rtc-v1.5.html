Free-RTC v1.5

Voice · Video · Chat

Good conversations shouldn't be complicated.

Free-RTC is a lightweight place to talk, share your screen, exchange messages, and send files with a small group — straight from your browser.

Voice & videoHop into a live room with up to 10 people.
Screen sharingShow a screen or window during the call.
Chat & pollsMessage each other and collect quick votes.
Direct file sharingShare files peer-to-peer when connected.
Your messages and shared files travel between people’s browsers. Firebase helps everyone join the same room and connect; it doesn’t save chat messages or shared files. Your chat history stays in your own browser.

Get into a room

Create a new room for your group, or join one with the three-digit code you were given.

Free-RTC version history

A release-by-release record of the features and improvements in this single-file application.

1.0

Original release

  • Created the original single-file web app for small voice and video rooms.
  • Added random three-digit room codes, optional room passwords, participant names and colors, and a ten-person room limit.
  • Used anonymous Firebase Authentication, Realtime Database presence and signaling, and WebRTC peer connections.
  • Included microphone mute, deafen, camera, screen sharing, participant controls, video quality presets, and a local soundboard.
1.1

Peer-to-peer chat

  • Added text messaging over WebRTC data channels rather than a Firebase message database.
  • Added a chat history stored locally in the user's browser, with sender names, timestamps, and a local clear-history control.
  • Introduced a dedicated chat panel and improved message input styling.
1.2

UI, accessibility and reliability

  • Added matching SVG icons for call controls, settings, chat, soundboard, and leaving a room.
  • Introduced coordinated Soundboard and Chat drawers, a draggable divider, floating settings and sound-effect modals, and responsive mobile styling.
  • Added sound-effect previews, per-action sound preferences, local audio upload, video quality settings, and clearer controls.
1.3

Chat, sharing, workspace and controls

  • Added WebRTC-based file offers and chunked transfers, file metadata and previews, receiver-initiated downloads, progress reporting, and send-buffer backpressure.
  • Added typing indicators, read receipts, reactions, replies, private messages, polls, temporary messages, and edit/unsend/delete/copy actions.
  • Integrated and resized the right-side workspace, added soundboard emoji labels and uploaded local sound effects, and introduced upload and expiration settings.
  • Improved screen-share track cleanup and added custom room IDs, which are reverted in v1.4 due to their additional database availability checks.
1.4

Room creation fix and landing-page redesign

  • Restored the original random three-digit room-code flow and removed the custom room ID field.
  • Removed the added /createdAt reads and transactions that conflicted with the deployed Firebase rules; added clearer permission-error handling and pending media cleanup.
  • Rebuilt the home page as a spacious two-column layout on desktop and a stacked mobile layout, with room creation and joining grouped in a dedicated card.
  • Added this full in-app version history covering releases 1.0 through 1.4.
1.5

Call layout and chat polish

CURRENT
  • Moved the call controls back to a full-width bar at the bottom, outside the main workspace flex row.
  • Preserved the integrated right-side Chat/Soundboard drawers and horizontal resizing handle.
  • Replaced always-visible message action buttons with a compact overflow menu.
  • Cleaned up image and video attachment previews, emphasizing the media and hiding redundant metadata from visual attachments.
  • Reworded the homepage privacy explanation in plain language.

Privacy note: messages and shared files travel between browsers. Firebase helps participants discover the room and set up the connection; it is not used to save chat messages or shared file contents. Each browser keeps its own local chat history.
