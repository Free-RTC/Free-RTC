Free-RTC v1.6

Voice · Video · Chat

Good conversations shouldn't be complicated.

Free-RTC is a lightweight place to talk, share your screen, exchange messages, and send files with a small group — straight from your browser.

Voice & videoHop into a live room with up to 10 people.
Screen sharingShow a screen or window during the call.
Chat & pollsMessage each other and collect quick votes.
Direct file sharingShare files peer-to-peer when connected.
Chat messages and shared files go straight between connected browsers using a direct connection called WebRTC. Firebase only helps everyone join the same room and connect; it does not store chat text or file contents. Your chat history is saved only on your own device.

Get into a room

Create a new room for your group, or join one with the three-digit code you were given.

OR JOIN AN EXISTING ROOM

Ask the room creator to share their code and password, if one is set.

Free-RTC version history

A release-by-release record of the features and improvements in this single-file application.

1.0

Original release

  • Introduced browser-based voice and video rooms with random three-digit codes, optional passwords, participant controls and a local soundboard.
1.1

Peer-to-peer chat

  • Added direct chat over WebRTC and local browser history, without a Firebase message database.
1.2

Interface and sound improvements

  • Added matching icons, coordinated side drawers, settings, configurable sound effects and improved responsive styling.
1.3

Chat and sharing features

  • Added peer-to-peer file transfers, message actions, reactions, polls, private messages, temporary messages and soundboard improvements.
1.4

Room creation and landing page

  • Restored random room codes, improved startup error reporting, redesigned the home screen and added the in-app release history.
1.5

Workspace and chat polish

  • Returned call controls to the bottom, refined the resizable workspace, streamlined message actions and improved media previews.
1.6

Chat, settings and media reliability

CURRENT
  • Reduced message-card spacing and moved read/sent status and message action icons into the header.
  • Replaced numeric upload limits with cap toggles, improved mobile layouts and aligned homepage feature icons.
  • Improved screen-share compatibility and connection recovery, protected large-file transfers, and fixed several chat and mobile layout bugs.

Privacy note: messages and shared files are sent directly between connected browsers. Firebase helps everyone join the room and establish a connection, but it does not store chat messages or shared file contents. Your chat history stays in your own browser.
